# 80p-1 (PDF 80쪽 = 교재 인쇄 78쪽, 유형 1 접선의 방정식, 대표기출 1번)

출처: 2024학년도 대수능 20번 [24107-0113], 주관식 [4점]
교재 정답·해설: 이 PDF 범위(1~81쪽)에 없음 → 대조 불가

## 원문
$a>\sqrt2$인 실수 $a$에 대하여 함수 $f(x)$를
$f(x)=-x^3+ax^2+2x$
라 하자. 곡선 $y=f(x)$ 위의 점 $O(0,0)$에서의 접선이 곡선 $y=f(x)$와 만나는 점 중 $O$가 아닌 점을 $A$라 하고,
곡선 $y=f(x)$ 위의 점 $A$에서의 접선이 $x$축과 만나는 점을 $B$라 하자.
점 $A$가 선분 $OB$를 지름으로 하는 원 위의 점일 때, $\overline{OA}\times\overline{AB}$의 값을 구하시오.

## p.80 1번. 답 25 (verify/80p-1.py)
- 일반해: O에서의 접선 $y=f'(0)x=2x$와 곡선을 연립 → $x^2(x-a)=0$, A$(a,2a)$.
  A에서의 접선 기울기 $f'(a)=2-a^2$. "A가 OB 지름 원 위" ⇔ $\angle OAB=90^\circ$ ⇔ $2(2-a^2)=-1$ ⇔ $a^2=\tfrac52$.
  $\overline{OA}\times\overline{AB}=2\triangle OAB=\overline{OB}\times y_A$, $x_B=\dfrac{a^3}{a^2-2}=2a^3$ → $2a^3\cdot2a=4a^4=25$.
  (다른 교점은 근과 계수의 관계로 구함: 최고차계수 $-1$, 이차항 $a$ → 세 근의 합 $a$ = $0+0+x_A$.)
- 특수 풀이:
  1. "원점 접선의 다른 교점은 $x=a$" 암기 → 최고차계수가 $-1$이 아니거나 접점이 원점이 아니면 깨짐 (예: $-2x^3+ax^2+x$ 이면 $x=\tfrac a2$).
  2. 원 조건을 곧바로 "기울기 곱 $-1$"로만 처리 → 직각 위치가 A로 고정된 원문에서만 충분. "직각삼각형" 조건이면 꼭짓점별 경우 분류가 빠짐.
  3. 그림처럼 B를 양의 $x$축에 두고 푸는 것 → $a>\sqrt2$ 덕분. 조건이 풀리면 B 위치를 식으로 확인해야 함.
- 더 일반적인 관점: $f(x)=-x^3+ax^2+mx$ 로 두면 $a^2=m+\tfrac1m$, $\overline{OA}\times\overline{AB}=(m^2+1)^2$ (verify/sweep_80p-1.py). 원문은 $m=2$.

## 3-A 조건 역추적
| 요소 | 이 조건이 잘라낸 경우 | 지우거나 바꾸면 생기는 일 |
|---|---|---|
| $a>\sqrt2$ | $a=\sqrt2$: A에서 접선 수평 → $x$축 교점 B 없음. $0<a<\sqrt2$: B가 음의 $x$축 | 지워도 원 조건에서 $a^2=\tfrac52$ 하나 → 답 불변. 단 $y$축으로 바꾸면 $a=\sqrt2$가 정답 경우로 살아남 |
| 기준 축 $x$축 | 수평 접선 경우(B 없음) | $y$축이면 B$(0,a^3)$ 항상 존재 → $\angle B=90^\circ$($a=\sqrt2$) 가능 |
| 점 O 고정(원점 접선) | 접점 ≠ 교점 공식 | 접점 이동 시 다른 교점 = $a-2t$ (근과 계수) |
| 도형 조건 "A가 OB 지름 원 위" | 직각 위치를 A로 고정 | "직각삼각형"이면 O·A·B 별 분류. $x$축 B에서는 A만 가능, $y$축 B에서는 A·B 가능 |
| 고정 계수 $2$ ($2x$) | — | $m$으로 바꿔도 논리 유지, 답 $(m^2+1)^2$ → 생존 확인형 |
| 최고차계수 $-1$ | "다른 교점 $x=a$" 지름길 | $-k$면 다른 교점 $x=\tfrac ak$ |

## 3-B 임계값 스윕 (verify/sweep_80p-1.py, $f=-x^3+ax^2+mx$, $a,m>0$)
- $a=\sqrt m$: A에서 접선 수평 → $x$축 B 없음, $y$축 B는 존재
- $a=0$: A=O (변곡점에서의 접선, 다른 교점 없음), B=O
- $x_B>0 \iff a>\sqrt m$ (원문 $a>\sqrt2$의 역할)
- 직각 위치: $x$축 B → A에서만 ($a^2=m+\tfrac1m$). $y$축 B → A ($a^2=m+\tfrac1m$), B ($a=\sqrt m$). O는 어느 쪽도 불가
