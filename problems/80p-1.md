# 80p-1 (PDF 80쪽 = 교재 인쇄 78쪽, 유형 1 접선의 방정식, 대표기출 1번)

출처: 2024학년도 대수능 20번 [24107-0113], 주관식 [4점]

## 원문
$a>\sqrt2$인 실수 $a$에 대하여 함수 $f(x)$를
$f(x)=-x^3+ax^2+2x$
라 하자. 곡선 $y=f(x)$ 위의 점 $O(0,0)$에서의 접선이 곡선 $y=f(x)$와 만나는 점 중 $O$가 아닌 점을 $A$라 하고,
곡선 $y=f(x)$ 위의 점 $A$에서의 접선이 $x$축과 만나는 점을 $B$라 하자.
점 $A$가 선분 $OB$를 지름으로 하는 원 위의 점일 때, $\overline{OA}\times\overline{AB}$의 값을 구하시오.

## 독립 풀이 (verify/80p-1.py로 확인)
1. $f'(0)=2$ → O에서의 접선 $y=2x$.
2. $-x^3+ax^2+2x=2x \Rightarrow x^2(x-a)=0$ → $A(a,\,2a)$.
3. $f'(a)=2-a^2$ ( $a>\sqrt2$ 이므로 $<0$, B 존재 ).
4. A가 OB를 지름으로 하는 원 위 ⇔ $\angle OAB=90^\circ$ ⇔ $2(2-a^2)=-1$ ⇔ $a^2=\tfrac52$.
5. $\overline{OA}\times\overline{AB}=2\triangle OAB=\overline{OB}\times y_A$, $x_B=\dfrac{a^3}{a^2-2}=2a^3$, $y_A=2a$ → $4a^4=25$.
