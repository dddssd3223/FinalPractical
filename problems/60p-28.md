# 60p-28 (PDF 60쪽 = 교재 58쪽, 28번)

출처: 2024년 수능특강 [24009-0063] · 주관식

## 원문
최고차항의 계수가 $1$인 다항함수 $f(x)$가 $\displaystyle\lim_{x\to\infty}\frac{f(x)}{xf'(x)}=\frac13$, $\displaystyle\lim_{x\to0}\frac{f(x)}{xf'(x)}=\frac13$을 만족시킬 때, $f(2)$의 값을 구하시오.

## p.60 28번. 답 8
- 일반해: f 의 최고차 n, 최저차 k (x^k 계수≠0) 이면 x→∞ 에서 f/(xf')→1/n, x→0 에서 →1/k. n=k=3 → f=x³ → f(2)=8.
- 특수 풀이: ① x→0 극한이 1/k 가 되려면 x^k 항 계수가 0 이 아니어야 함 — 계수가 0 이 되는 해는 최저차가 달라져 버려야 함.
- 더 일반적인 관점: f/(xf') 는 최고차항(∞)·최저차항(0)만 보는 식.

## 3-A 조건 역추적
| 요소 | 이 조건이 잘라낸 경우 | 지우거나 바꾸면 생기는 일 |
|---|---|---|
| 최저차 = 최고차 = 3 (한 항뿐) | 최저차 < 최고차 (계수 결정 필요, 계수 0 인 해 제외) | x→0 값 1/2 이면 f=x³+ax², a≠0 확인 필요 |
| 극한값 1/3 | — | 둘 다 1/4 이면 f=x⁴ (생존) |

## 3-B 임계값 스윕
- 1/n 에서 n=최고차, 1/k 에서 k=최저차(계수≠0)
