# 68p-45 (PDF 68쪽 = 교재 66쪽, 45번)

출처: 2025년 수능특강 [25009-0073] · 객관식

## 원문
다항함수 $f(x)$와 연속함수 $g(x)$가 다음 조건을 만족시킬 때, $f'(0)$의 값은?
- (가) $f(0)=0$, $g(0)=5$
- (나) 모든 양수 $x$에 대하여 $f(x)>0$이다.
- (다) 모든 양수 $t$에 대하여 점 $(t,\,f(t))$와 원점 사이의 거리는 $tg(t)$이다.
선지: ① 2*sqrt(6) / ② 5 / ③ sqrt(26) / ④ 3*sqrt(3) / ⑤ 2*sqrt(7)

## p.68 45번. 답 2*sqrt(6)
- 일반해: t>0: √(t²+f²)=tg → g=√(1+(f/t)²). g 연속 → t→0+: √(1+f'(0)²)=5 → f'(0)²=24. f(0)=0, x>0 에서 f>0 → f'(0)>0 → 2√6.
- 특수 풀이: ① f/t → f'(0) 의 부호는 f 의 부호 ÷ t 의 부호 — 음수 쪽에서 f>0 이면 f'(0)<0.
- 더 일반적인 관점: 거리식을 g 로 풀고 0 에서 연속.

## 3-A 조건 역추적
| 요소 | 이 조건이 잘라낸 경우 | 지우거나 바꾸면 생기는 일 |
|---|---|---|
| 양수 t 쪽 (t>0, f>0 → f'(0)>0) | 음수 t 쪽 (t<0, f>0 → f'(0)<0) | 음수 쪽이면 g=−√(1+(f/t)²), g(0)=−5, f'(0)=−2√6 |
| g(0)=5 | — | 3 이면 f'(0)=2√2 (생존) |

## 3-B 임계값 스윕
- f'(0)²=g(0)²−1
