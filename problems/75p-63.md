# 75p-63 (PDF 75쪽 = 교재 73쪽, 63번)

출처: 2025학년도 수능 9월 모의평가 21번 · 주관식

## 원문
최고차항의 계수가 $1$인 삼차함수 $f(x)$가 모든 정수 $k$에 대하여 $2k-8\le \frac{f(k+2)-f(k)}{2}\le 4k^2+14k$를 만족시킬 때, $f'(3)$의 값을 구하시오.

## p.75 63번. 답 31
- 일반해: D(k)=(f(k+2)−f(k))/2. 위 여유 U=4k²+14k−D, 아래 여유 L=D−(2k−8), U+L=4(k+1)(k+2) → k=−1,−2 에서 U=L=0. U 는 최고차 1 인 이차 → U=(k+1)(k+2) → D=3k²+11k−2. f=x³+px²+qx: D=3k²+(6+2p)k+4+2p+q → p=5/2, q=−11 → f'(3)=31.
- 특수 풀이: ① 합 U+L 이 정수 k=−1,−2 에서 0 — 두 여유가 모두 0 이 되어 D 가 결정. ② (f(k+2)−f(k))/2 = f'(k+1)+1 (삼차의 셋째 항) — 미분계수와 1 차이.
- 더 일반적인 관점: 위·아래 경계의 차가 정수에서 0 이 되는 점을 찾기.
